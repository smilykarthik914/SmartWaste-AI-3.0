# SmartWaste-AI-3.0
CNN and MobileNetV2 based Intelligent Waste Classification System with Grad-CAM Explainable AI.

SmartWaste AI 3.0 ♻️
Intelligent Waste Classification Using CNN and MobileNetV2

Project Overview

SmartWaste AI 3.0 is an AI-powered waste classification system that uses Convolutional Neural Networks and MobileNetV2 transfer learning to identify different types of waste from uploaded images.

Technologies Used

* Python
* TensorFlow / Keras
* CNN
* MobileNetV2
* Transfer Learning
* Grad-CAM
* Gradio
* Google Colab

Waste Categories

1. Cardboard
2. Glass
3. Metal
4. Paper
5. Plastic
6. Trash

Key Features

* Image-based waste classification
* MobileNetV2 transfer learning
* Grad-CAM visual explanations
* Recycling recommendations
* Interactive Gradio web interface
* Model performance comparison

Model Performance

Model	Test Accuracy
Custom CNN	71.32%
Class-weighted CNN	72.37%
MobileNetV2	88.68%

How to Run

1. Open the Jupyter Notebook in Google Colab.
2. Enable GPU acceleration if available.
3. Run the notebook cells in order.
4. Upload a waste image through the Gradio interface.
5. View the predicted category and explanation.

Project Disclaimer

This is an educational machine learning project. Classification results depend on image quality and dataset characteristics.
